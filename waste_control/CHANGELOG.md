# Changelog

All notable changes to **WasteControl-io** will be documented in this file.

## [0.1.0] - 2026-10-12
### Added
- Initial project scaffolding and Home Assistant Add-on repository structure.
- Multi-stream schedule engine supporting weekly, bi-weekly (odd/even), monthly, and holiday delay adjustments.
- Smart bin telemetry tracking with ultrasonic depth-to-percentage fill conversion.
- Tri-state location tracking (`storage`, `transit`, `curb`).
- Zero-config Home Assistant MQTT Auto-Discovery for sensors, binary sensors, and buttons.
- Responsive dark-themed Ingress web dashboard with live fill gauges and quick actions.
- Turnkey ESP32 ESPHome firmware configurations for weatherproof ultrasonic and BLE presence tracking.
- Custom PCB art branding matching the Paradigm-Paradox `*-io` hardware identity.
