# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-12
### Added
- Initial project architecture and Home Assistant add-on repository definition.
- Support for multi-architecture builds (AMD64, ARM64, ARMv7).
- Ingress-ready web dashboard with real-time sensor visualization and pump controls.
- Configurable closed-loop dosing engine for pH and EC management.
- Multi-tier safety guards: mixing delay intervals, max single dose limits, and daily caps.
- Irrigation duty cycle scheduler (continuous, cyclic interval, flood & drain).
