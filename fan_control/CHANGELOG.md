# Changelog

All notable changes to **FanControl-io** will be documented in this file.

## [0.1.0] - Initial Release

### Added
- Multi-architecture Home Assistant Add-on packaging (`aarch64`, `amd64`, `armhf`, `armv7`, `i386`).
- Native Ingress web dashboard with real-time fan RPM, PWM duty cycle controls, and thermal telemetry.
- Support for ESP32 microcontrollers over Wi-Fi, Wired Ethernet (WT32-ETH01, Olimex PoE), and BLE tracking.
- Delta-T rack cabinet thermal algorithm and curve presets (`auto`, `silent`, `balanced`, `performance`, `turbo`).
- Real-time tachometer pulse counting and stall detection alarm.
- Ready-to-flash ESPHome YAML templates with autonomous edge-level watchdog failsafe.
- High-resolution vintage PCB art icon and logo.
